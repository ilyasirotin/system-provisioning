# Useful system shortcuts

### System
- **⌘ + Option + Esc** -> Force Quit

### Finder
- **⌘ + Shift + G** -> Go to folder (you can paste any path)
- **⌘ + Shift + H** -> Open Home directory
- **⌘ + Shift + D** -> Desktop
- **⌘ + Shift + O** -> Documents
